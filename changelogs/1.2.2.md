# BetterBedWars v1.2.2 - Changelog

### 🏆 New Victory Scoreboard
- At the end of a match, the members of the **winning team** now see a **dedicated scoreboard** showing their team name followed by **"VICTORY"**, along with their kills and coins:
  ```
  VICTORY
  Red Team
  has won the game!
  Kills: X
  Coins earned: X
  ```
- **Losers and spectators** now see the name of the team that actually won (e.g. "Red Team VICTORY") instead of the generic "VICTORY!", so it's clear at a glance which team took the win.
- In case of a **tie (TIE)**, the behavior remains unchanged.
- The winning team is determined only once when the match ends: it cannot change even if a player disconnects during the end-game screen.

### 🛠️ Fixes
- **Fixed respawn crash**: fixed the `Position world is null or has been unloaded` crash that occurred during a player's respawn, caused by the world reference stored in the team spawn point.
- **Fixed server startup crash (MapFactory)**: fixed the `Team::__construct` TypeError that received a `Mode` enum instead of the integer number of players per team. The server failed to start in certain configurations.
- **Fixed setup items**: map setup items were not working during map creation/editing due to a case-sensitivity mismatch when looking up configuration keys.
- **Fixed `EndingStage::getTitle()`**: method made public to fix a visibility error when displaying the end-of-match scoreboard.
- **Scoreboard compatibility**: added compatibility with newer PocketMine-MP 5 builds, which use an action enum for scoreboard packets instead of the integer `type` field.
