# BetterBedWars v1.4.0 - Changelog

Maintenance and stability release focused on MySQL session loading correctness and safer game world cleanup.

### 🛠️ Fixes

**Providers / Sessions**
- **MySQL async session load stat merge**: stats earned while an async MySQL session load is in flight are now added to the stored database values instead of being overwritten or only applied when the in-memory value is `0`. This prevents losing coins, kills, or wins granted during login/load.
- **Persist merged stats after async load**: when the merged totals differ from the values read from the database, the provider now persists the updated coins, kills, and wins after the session finishes loading (increments earned during loading are not written while `loading_data` is `true`).
- **Stale async load completion guard**: `LoadSessionTask` now ignores completions when the session no longer exists or is no longer in a loading state.

**Game world cleanup**
- **Safer world folder removal task**: `RemoveGameTask` now checks that the game world directory exists before attempting recursive deletion, avoiding errors when the folder was already cleaned up.
- **Synchronous cleanup on plugin disable**: on shutdown, active game worlds are now unloaded and their copied world folders are removed synchronously instead of relying on async pool tasks that may not complete before the server stops.

### ✨ Added
- **`Session::isLoadingData()`**: exposes the session loading state so async providers can safely detect whether a load completion is still valid.

### 🗑️ Removed
- None.
